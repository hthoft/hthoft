## Hi, I'm Hans

Co-founder & CTO at [Maprova](https://maprova.dk), based in Aalborg, Denmark.

Maprova is a workforce and production platform for Danish manufacturers. One system covers:

- Time and attendance, absence and payroll export
- Production planning, jobs and quality control
- Live shop-floor boards, RFID kiosks and label printing
- ERP integration (Business Central, Dynamics AX)

### What I work with

- **Software:** TypeScript · Next.js · React · PostgreSQL · Prisma · Redis / BullMQ
- **Infrastructure and networks:** Linux servers · Docker · Ansible · VPN · Grafana / OpenTelemetry
- **Hardware:** shop-floor screens and kiosks · RFID readers · label printers · Raspberry Pi · embedded C++
- **Modeling:** 3D modeling and CAD · robot simulation · data modeling
